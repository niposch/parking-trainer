# Parking Trainer

Research and requirements for a focused parking practice game. **No implementation yet.**

Read [the requirements and asset shortlist](docs/requirements.md).

Current direction: C# with Godot 4.7.2 Mono, Windows, Steam Input, automatic-car controls, procedural parking exercises, and an optional visual tutor. Simple unbranded vehicles; reuse existing assets with small adjustments.

This folder is a standalone Git repository inside the current workspace. Run Git commands from this folder. No remote or publishing destination is configured.
